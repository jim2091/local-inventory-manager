# local-inventory-manager
아부지 요청으로 간단한 개인 사업자용 재고관리 엑셀파일 관리 프로그램

# 재고관리 프로그램

기존 Excel VBA 기반 재고관리 프로그램을 **Electron + React 기반의 Windows 데스크톱 애플리케이션**으로 전환하는 프로젝트입니다.

기존 Excel 데이터를 그대로 활용하면서도 컴퓨터 사용에 익숙하지 않은 사용자도 일반 프로그램처럼 쉽게 설치하고 사용할 수 있는 것을 목표로 합니다.

---

## 프로젝트 목표

기존 프로그램은 Excel과 VBA UserForm을 이용하여 입고, 출고, 출고반입 및 현재재고를 관리하고 있습니다.

기존 Excel 방식의 장점은 유지하면서 다음 부분을 개선하는 것이 목표입니다.

* 입출고 등록 편의성 개선
* 입출고 내역 검색 및 조회
* 품목 / 거래처 관리
* 잘못 등록한 입출고 취소
* 재고 정합성 검사
* 자동 및 수동 백업
* 기존 Excel 데이터 가져오기
* 데이터 손상 및 비정상 종료 대비
* 일반 Windows 프로그램과 같은 설치 및 실행 경험 제공

프로그램의 가장 중요한 기준은 UI의 화려함보다 **컴퓨터에 익숙하지 않은 사용자도 쉽게 사용할 수 있는가**입니다.

---

## 사용 환경

1차 버전은 다음 환경을 대상으로 합니다.

* Windows
* 한 대의 PC
* 한 번에 한 사용자
* 인터넷 연결 불필요
* 별도 서버 불필요
* 별도 데이터베이스 불필요

최종 사용자는 Node.js, Java, DB 등의 개발 환경을 별도로 설치하지 않고 설치 프로그램을 통해 프로그램을 사용할 수 있도록 하는 것을 목표로 합니다.

---

## 프로그램 구조

```text
React UI
   ↓
inventoryApi
   ↓
Electron Preload
   ↓
IPC
   ↓
Electron Main
   ↓
Excel / Local File System
```

React 컴포넌트가 Excel 파일이나 Node.js 파일 시스템에 직접 접근하지 않도록 구성합니다.

향후 여러 PC에서 동시에 사용하는 구조가 필요할 경우 데이터 접근 계층만 서버 API 방식으로 변경할 수 있도록 설계합니다.

```text
현재
React → Electron → Excel

향후 확장
React → HTTP API → Server → DB
```

## 데이터 구조

업무 데이터는 기본적으로 다음 Excel 파일에서 관리합니다.

```text
재고관리데이터.xlsx
```

사용자 데이터는 프로그램 설치 경로와 분리합니다.

예정된 기본 구조:

```text
문서/
└─ 재고관리 프로그램/
   ├─ 재고관리데이터.xlsx
   ├─ backup/
   └─ export/
```

프로그램을 업데이트하거나 다시 설치해도 기존 업무 데이터는 유지할 수 있도록 설계합니다.

## 주요 기능

### 입출고 등록

* 입고
* 출고
* 출고반입
* 거래처 검색
* 품목 검색 및 자동완성
* 수량 / 단가 입력
* 공급가 / 부가세 / 합계 자동 계산
* 현재재고 자동 반영
* 재고 부족 시 경고 후 마이너스 재고 허용
* 등록 즉시 자동 저장

### 입출고 조회

* 기간 검색
* 거래구분 검색
* 거래처 검색
* 품목 검색
* 정렬
* 페이지네이션
* 입출고 수량 및 금액 합계
* 취소 내역 포함 조회
* 조회 결과 Excel 내보내기

### 입출고 취소

잘못 등록한 입출고 내역을 직접 수정하거나 삭제하지 않고 취소 상태로 변경합니다.

취소 시 기존 기록을 보존하고 재고를 반대로 복구합니다.

### 품목 관리

* 목록 조회
* 검색
* 등록
* 수정
* 삭제
* 품목코드 중복 방지

입출고 이력이 존재하는 품목의 코드는 변경하거나 삭제할 수 없도록 처리합니다.

### 거래처 관리

* 매입거래처
* 매출거래처
* 목록 조회
* 검색
* 등록
* 수정
* 삭제
* 거래처코드 중복 방지

### 재고 정합성 검사

기초재고와 입출고 내역을 기준으로 계산한 재고와 현재재고를 비교합니다.

```text
계산재고
=
기초재고
+ 입고
+ 출고반입
- 출고
```

차이가 있는 품목만 표시하며 현재재고를 자동으로 수정하지는 않습니다.

### 백업 및 복원

* 자동 백업
* 수동 백업
* 백업 파일 목록
* 백업 복원
* 백업 폴더 열기
* 오래된 백업 자동 정리

## 기존 Excel 데이터 활용

기존에 사용하던 Excel VBA 파일의 데이터를 버리지 않고 신규 프로그램으로 가져올 수 있도록 구현합니다.

대상 데이터:

* 입출고내역
* 품목
* 매출거래처
* 매입거래처

기존 파일은 읽기 전용 원본으로 취급하며 프로그램이 직접 수정하지 않습니다.

가져온 데이터는 새로운 `재고관리데이터.xlsx` 파일에 저장합니다.

---

## 데이터 안전성

Excel을 데이터 저장소로 사용하는 만큼 데이터 안전성을 중요하게 다룹니다.

저장 시 원본 파일을 바로 덮어쓰지 않고 다음과 같은 방식을 적용할 예정입니다.

```text
기존 데이터 읽기
→ 변경사항 적용
→ 임시 Excel 파일 생성
→ 임시 파일 검증
→ 기존 파일 백업
→ 정상 파일 교체
```

다음 상황도 고려합니다.

* Excel에서 데이터 파일을 열어둔 상태
* 저장 도중 프로그램 종료
* PC 비정상 종료
* 임시 파일 잔존
* Excel 파일 손상

## 사용자 편의성 원칙

이 프로젝트는 다음 원칙을 우선합니다.

1. 컴퓨터에 익숙하지 않은 사용자도 사용할 수 있어야 한다.
2. 사용자가 서버나 DB를 몰라도 되어야 한다.
3. 프로그램을 더블클릭하면 바로 사용할 수 있어야 한다.
4. 일반적인 작업은 자동 저장한다.
5. 위험한 작업만 명확하게 확인한다.
6. 오류 메시지는 쉬운 한국어로 제공한다.
7. 실수했을 때 데이터 복구가 쉬워야 한다.
8. 기존 Excel 데이터를 최대한 활용한다.
